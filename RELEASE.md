## 📖 Описание

Интерактивный образовательный сайт (SPA) по математике для учеников 5 класса. Сайт посвящён темам **Наибольший Общий Делитель (НОД)** и **Наименьшее Общее Кратное (НОК)**. Работает как web-app: устанавливается на домашний экран iPhone/iPad (манифест PWA и подборка иконок под разные модели).

### 🧮 Калькулятор НОД/НОК: третье число

## 📦 Полный список возможностей приложения

### 📚 Теория
- Вводный раздел с определениями НОД и НОК (`TheoryIntro`)
- Разделы с объяснениями и примерами разложения на множители: НОД (`NODTheory`), НОК (`NOKTheory`)
- Наглядные карточки с делителями и кратными числами, пошаговые решения

### 🧮 Калькулятор НОД/НОК
- Вычисление для двух или трёх чисел, режимы НОД/НОК на интерактивных вкладках
- Пошаговое решение с разложением на простые множители
- История вычислений

### 📝 Практика
- **60 задач**, генерируемых случайным образом: 🟢 лёгкий (2–20), 🟡 средний (10–50), 🔴 сложный (20–100, иногда 3 числа) — по 20 задач уровня (10 НОД + 10 НОК)
- Фильтр по сложности, проверка ответа, подсказки и полные решения
- Панель прогресса со счётчиком верных ответов и сброс результатов

### ✅ Тест «Проверь себя»
- 10 вопросов с вариантами ответов, случайное перемешивание вопросов и вариантов (алгоритм Фишера–Йетса)
- Мгновенная проверка с объяснением, итоговая оценка, разбор ошибок
- Конфетти при отличном результате (canvas-confetti)

### 🎨 Интерфейс
- Адаптивная вёрстка для мобильных и десктопов, анимации появления секций (Framer Motion)
- Шапка с навигацией (Главная, Теория, НОД, НОК, Калькулятор, Практика), мобильное меню, кнопка «Проверь себя»
- Плавная прокрутка между разделами
- Цветовая индикация разделов: Теория — синий, НОД — красный (#FF6B6B), НОК — бирюзовый (#4ECDC4), Калькулятор — пурпурный, Практика — зелёный

## 🛠 Технические детали

### Стек технологий
- **React 19** + **TypeScript ~5.9** — UI и типизация
- **Vite 7** — сборщик (`base: './'`, алиас `@` → `src`)
- **Tailwind CSS 3.4** + tailwindcss-animate — стилизация
- **shadcn/ui** + Radix UI — библиотека компонентов (`src/components/ui/`)
- **Framer Motion** — анимации
- **lucide-react** — иконки, **canvas-confetti** — конфетти в тесте

## 📦 Установка, запуск и сборка

```bash
git clone https://github.com/osmaav/mathematics_nok_nod.git
cd mathematics_nok_nod
npm install        # Node.js 20+
npm run dev        # dev-сервер
npm run build      # проверка типов + сборка в dist/
npm run preview    # просмотр собранной версии
npm run lint       # ESLint
```

---

## 🚀 Публикация релиза

1. Изменения объединяются в ветку `main`.
2. Push в `main` запускает workflow **Deploy to GitHub Pages** (`.github/workflows/deploy.yml`): `npm ci` → `npm run build` → публикация `dist/`.
3. Релиз фиксируется git-тегом `v2.2.0`.

> Примечание: скрипт `npm run icons` в `package.json` ссылается на отсутствующий в репозитории `scripts/generate-icons.py`; готовые иконки закоммичены в `public/icons/` и генерация при сборке не требуется.
