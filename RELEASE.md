# 🎓 Математика 5 класс: НОД и НОК

**Версия:** 2.1.0  
**Дата релиза:** 20 февраля 2026  
**Сайт:** https://osmaav.github.io/mathematics_nok_nod/

---

## 📖 Описание

Интерактивный образовательный сайт по математике для учеников 5 класса. Сайт посвящён изучению тем **Наибольший Общий Делитель (НОД)** и **Наименьшее Общее Кратное (НОК)** по программе ФГОС России.

---

## ✨ Основные возможности

### 📚 Теоретический раздел
- Вводный раздел с определениями НОД и НОК
- Подробные объяснения с примерами разложения на множители
- Наглядные карточки с делителями и кратными числами
- Пошаговые решения с анимацией

### 🧮 Калькулятор НОД/НОК
- Вычисление НОД и НОК для любых двух чисел
- Пошаговое решение с разложением на простые множители
- История вычислений
- Интерактивные вкладки для переключения между НОД и НОК

### 📝 Практика
- **60 задач** сгенерированных случайным образом
- 3 уровня сложности:
  - 🟢 **Лёгкий**: 20 задач (числа от 2 до 20)
  - 🟡 **Средний**: 20 задач (числа от 10 до 50)
  - 🔴 **Сложный**: 20 задач (числа от 20 до 100, иногда 3 числа)
- Проверка ответа по нажатию Enter или кнопки
- Подсказки к каждой задаче
- Полные решения с разложением на множители
- Прогресс-бар с процентом выполнения
- Сброс прогресса

### ✅ Тест (Проверь себя)
- 10 вопросов с вариантами ответов
- Случайное перемешивание вопросов и вариантов ответов
- Мгновенная проверка с объяснением правильного ответа
- Подсчёт результатов с оценкой
- Разбор ошибок в конце теста
- Конфетти при отличном результате (8+ правильных ответов)

### 🎨 Интерфейс
- Адаптивный дизайн для мобильных и десктопов
- Плавная навигация между разделами
- Автоматическая подсветка активного раздела в шапке
- Цветовая индикация для каждого раздела:
  - Теория — синий
  - НОД — красный
  - НОК — фиолетовый
  - Калькулятор — пурпурный
  - Практика — зелёный

## 🛠 Технические детали

### Стек технологий
- **React 19** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **Tailwind CSS** — стилизация
- **Framer Motion** — анимации
- **shadcn/ui** — компоненты

### Структура проекта
```
src/
├── components/     # UI компоненты
├── contexts/       # React контексты
│   └── ActiveSectionContext.tsx
├── hooks/          # Кастомные хуки
│   └── useSectionVisibility.ts
├── lib/            # Утилиты и математические функции
│   └── math.ts
├── sections/       # Секции приложения
│   ├── Header.tsx
│   ├── Hero.tsx
│   ├── TheoryIntro.tsx
│   ├── NODTheory.tsx
│   ├── NOKTheory.tsx
│   ├── Calculator.tsx
│   ├── Practice.tsx
│   └── Quiz.tsx
└── types/          # TypeScript типы
```

## 📦 Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/osmaav/mathematics_nok_nod.git

# Перейти в директорию
cd mathematics_nok_nod

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Собрать проект
npm run build
```
