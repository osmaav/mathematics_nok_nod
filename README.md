# 🎓 Математика 5 класс: НОД и НОК

**Версия:** 2.7.0 · **Сборщик:** Vite 7 · **Язык интерфейса:** русский

Интерактивный образовательный одностраничный (SPA) сайт по математике для учеников 5 класса, посвящённый темам **Наибольший Общий Делитель (НОД)** и **Наименьшее Общее Кратное (НОК)**. Сайт работает как web-app: поддерживает установку на домашний экран iPhone/iPad (PWA-манифест и набор иконок), корректно отображается на мобильных устройствах и десктопах и публикуется на GitHub Pages через GitHub Actions.

## ✨ Возможности

### 📚 Теория
- Вводный раздел с определениями НОД и НОК (`TheoryIntro`)
- Отдельные разделы с подробными объяснениями и примерами: НОД (`NODTheory`) и НОК (`NOKTheory`)
- Наглядные карточки с делителями и кратными числами, пошаговые решения

### 🧮 Калькулятор НОД/НОК
- Вычисление НОД и НОК для **двух ИЛИ трёх** чисел (v2.7.0): третье число — необязательное поле («Можно оставить пустым»); если оно не заполнено — вычисление выполняется для двух чисел, если заполнено — для трёх
- Пошаговое решение подписано по шагам исправленного алгоритма из теории (v2.7.0): «Шаг 1. Каноническое разложение» → «Шаг 2. Алфавитный список оснований» → «Шаг 3. Выбор минимальной/максимальной степени» → «Шаг 4. Результат»
- Разложение на простые множители **в виде степеней** (v2.4.0): «72 = 2³ · 3² · 5⁰», выбор основания — «максимальная степень из 3, 1, 1 → 2³», итог — «НОК(72, 90, 150) = 2³ · 3² · 5² = 1800»
- История вычислений (сохраняются все участвующие числа — 2 или 3)
- Интерактивные вкладки для переключения между НОД и НОК

### 📝 Практика
- **60 задач**, генерируемых случайным образом при загрузке
- Фильтр по уровням сложности: 🟢 лёгкий (числа 2–20), 🟡 средний (10–50), 🔴 сложный (20–100, иногда 3 числа) — по 20 задач каждого уровня (10 НОД + 10 НОК)
- Проверка ответа, подсказки и полные решения с разложением на множители
- Панель прогресса («Ваш прогресс» / счётчик верных ответов) и сброс результатов

### ✅ Тест «Проверь себя»
- 10 вопросов с вариантами ответов
- Случайное перемешивание вопросов и вариантов ответов (алгоритм Фишера–Йетса)
- Мгновенная проверка с объяснением правильного ответа
- Итоговая оценка и разбор ошибок, конфетти при отличном результате

### ✏️ Запись со степенями вместо перемножений (v2.4.0, уточнено в v2.5.0)
- Все примеры теории (НОД(36, 48), НОК(4, 6)), пошаговые решения упражнений, объяснения теста и вывод калькулятора используют каноническую запись степенями: «2 × 2 × 3» → «2² · 3¹», «2 × 2 × 2 × 3» → «2³ · 3¹»
- С v2.5.0 — единый формат с явными показателями степени («3¹» вместо «3»), нулевые степени видны явно («5⁰»), как в таблицах-шпаргалках
- Итоги примеров записаны свёрнуто: «2² · 3¹ = 12» (без промежуточного «4 × 3»)
- Новая утилита `formatPowersFromCounts()` и надстрочные индексы `toSuperscript()` в `src/lib/math.ts`

### 📚 Теория НОД (v2.5.0)
- Пошаговый алгоритм нахождения НОД переписан по образу объяснения (по аналогии с алгоритмом НОК): главное правило работы со степенями → каноническое разложение (пример НОД(72, 90, 150)) → алфавитный список оснований → выбор минимальной степени (роль нулевой степени) → запись и вычисление результата (2¹ · 3¹ = 6)
- Таблица-шпаргалка «Как оформить это в тетради» (критерий выбора — минимальная степень, «5⁰ (не пишем)»)
- Блок «Связь двух алгоритмов (методический совет)» (v2.6.0 — отдельная карточка сразу после примера НОК в разделе НОК): сравнительная таблица НОК/НОД и мнемоническое правило («сборная солянка» — max, «общий знаменатель» — min); в разделе НОД — краткая отсылка со ссылкой на раздел НОК

### 📚 Теория НОК (v2.3.0)
- Пошаговый алгоритм нахождения НОК переписан по образу объяснения: каноническое разложение (пример НОК(72, 90, 150)) → алфавитный список оснований → выбор максимальной степени → запись и вычисление результата
- Предупреждение о типичной ошибке учеников (складывать степени или брать среднее значение)
- Блок «Самопроверка»: делимость результата на исходные числа и формула НОК(a, b) = a·b / НОД(a, b)
- Таблица-шпаргалка «Как оформить это в тетради» (основание × число × выбор для НОК)

### 🎨 Интерфейс
- Адаптивная вёрстка (Tailwind CSS), анимации появления секций (Framer Motion)
- Шапка с навигацией, мобильное меню и кнопка «Проверь себя»
- Перекрёстная ссылка в конце шапки (справа) на сайт «Правила делимости» — открывается в текущей вкладке (v2.2.1)
- Подвал в стиле проекта mathematics-divisibility: 🎓 «Математика 5 класс — НОД и НОК», «Интерактивный учебный ресурс», «Сделано с ❤️ для сына Андрея» (v2.2.0); ссылка из подвала открывается в текущей вкладке (v2.2.1)
- Автоматическая подсветка активного раздела при прокрутке (Intersection Observer, `ActiveSectionContext` + `useSectionVisibility`)
- Плавная прокрутка к разделам

## 🚀 Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/osmaav/mathematics_nok_nod.git
cd mathematics_nok_nod

# Установить зависимости (Node.js 20+)
npm install

# Запустить dev-сервер
npm run dev

# Проверка типов и сборка production-версии в dist/
npm run build

# Просмотр собранной версии
npm run preview

# Линтинг
npm run lint
```
